# RESUMIND — PREMIUM AI RESUME PLATFORM LANDING PAGE

You are a senior frontend engineer and SaaS product designer.

I have an existing full-stack application called **Resumind**, an AI-powered resume analysis and optimization platform.

Your task is to build a **premium, modern, highly responsive landing page for Resumind** that matches the existing application's UI/branding instead of creating a completely unrelated design.

IMPORTANT:

* First inspect the existing Resumind frontend.
* Understand its colors, typography, spacing, buttons, cards, borders, shadows, icons, navbar, dashboard and overall visual language.
* Reuse the existing design system wherever possible.
* Do NOT redesign the existing dashboard.
* Only create/improve the public-facing landing page.
* The landing page must feel like the same product as the existing Resumind application.

---

# 1. PRODUCT

## Product Name

**Resumind**

## Product Description

Resumind is an AI-powered resume intelligence platform that helps students, freshers and job seekers analyze, improve and optimize their resumes for real-world job applications.

The user uploads their resume and Resumind analyzes it, identifies weaknesses, provides ATS-focused suggestions, rewrites sections, compares the resume against job descriptions and helps users create a stronger, more job-ready resume.

The core product flow is:

**Upload Resume → Analyze → Identify Problems → Improve → Match With Jobs → Export**

# 28. IMPLEMENTATION PROCESS

Before writing code:

1. Inspect the existing Resumind frontend.
2. Identify the current design system.
3. Identify existing reusable components.
4. Identify existing routes.
5. Identify the authentication flow.
6. Identify the dashboard's visual style.
7. Identify existing icons/assets.
8. Then design the landing page around that system.

After implementation:

1. Run the project.
2. Check console errors.
3. Check routing.
4. Check desktop layout.
5. Check mobile layout.
6. Check every CTA.
7. Check navbar links.
8. Check animations.
9. Remove unused imports.
10. Ensure the landing page does not break any existing Resumind functionality.

Do not replace working application logic.

Do not modify backend APIs unless absolutely necessary.

The final result should feel like:

**"This landing page belongs to the exact same Resumind product."**
